# Учить текст

Тренажёр роли для труппы: пьеса В. Красногорова «Райские врата». Актёр выбирает роль, читает текст с подсвеченной ролью и прогоняет сцены: партнёры звучат по очереди, своя реплика показана первыми буквами — вспомнил, открыл, сверил. Прогресс — пройденные сцены и время тренировок. Работает на телефоне и без сети.

Статическое PWA на GitHub Pages без бэкенда: текст пьесы зашит в сборку, партнёров озвучивают заранее сгенерированные нейроголоса (Silero, Piper), а если клипа нет — голос браузера. Прогресс хранится только на устройстве (IndexedDB) и переносится файлом резервной копии.

Архитектура, требования и обоснование методов — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Режимы

| Режим | Что делает |
|---|---|
| Текст | Вся пьеса, подсвечена своя роль; поиск, переход к сцене, избранное и «Прогон отсюда» |
| Прогон с буквами | Сцена лентой: партнёры звучат, своя реплика первыми буквами. Ход: «все реплики по очереди» или «сразу к моим репликам» |
| Первые буквы | Подсказка партнёра звучит, своя реплика первыми буквами слов с пунктуацией |
| Аудиопрогон | Только звук: партнёры, тишина на своей реплике, «эхо»; управление с гарнитуры |

В любом режиме лист «Навигация» переносит к нужному месту диалога: по сценам, поиском по словам или из избранного.

## Быстрый старт

Нужен Node.js 22+.

```bash
npm ci
npm run dev          # разбор пьесы и dev-сервер: http://localhost:5173/text-learning/
```

Без сгенерированного аудио партнёров читает голос браузера — для разработки этого достаточно.

## Команды

| Команда | Что делает |
|---|---|
| `npm run parse` | `content/*` → `src/data/play.json` и `cast.json`, валидация и снапшот численности |
| `npm run parse -- --update-snapshot` | Обновить снапшот после осознанной правки текста |
| `npm run scenes:suggest` | Черновик карты сцен по входам и выходам персонажей |
| `npm run build` / `npm run preview` | Сборка в `dist/` и локальный просмотр сборки |
| `npm test` / `npm run coverage` | Юнит- и компонентные тесты (Vitest), покрытие `engine/` ≥ 90 % |
| `npm run e2e` | Playwright на собранном приложении (Chromium и WebKit) |
| `npm run lint` / `npm run typecheck` | ESLint и TypeScript strict |
| `npm run tts` | Сгенерировать недостающие клипы озвучки (нужны Python и ffmpeg) |
| `npm run check:size` | Размер `dist/` ≤ 100 МБ |
| `npm run icons` / `npm run silence` | Перерисовать иконки PWA / клип тишины |

Перед первым `npm run e2e` установите браузеры: `npx playwright install chromium webkit`.

## Контент

Всё, что касается пьесы, лежит в `content/` и правится без изменения кода:

- `raiskie-vrata.txt` — текст пьесы (UTF-8). Формат реплики: `ИМЯ. текст (ремарка.) текст`; строка с отступом в 4 пробела продолжает реплику после ремарки.
- `characters.yaml` — персонажи, их написания в тексте, группы и пол.
- `scenes.yaml` — карта сцен; границы задаются id первой реплики или ремарки сцены.
- `voices.yaml` — голос для каждого персонажа и рассказчика.
- `pronunciations.yaml` — ударения и точечные правки омографов для синтеза.
- `overrides.yaml` — ручная трактовка неоднозначных строк по номеру строки.

Если правка текста меняет число реплик или ремарок, сборка остановится на снапшоте. Проверьте разбор и обновите снапшот командой `npm run parse -- --update-snapshot` в том же PR. Прогресс актёров по изменённым репликам сбросится точечно, остальное сохранится.

## Озвучка

При деплое клипы генерируются в GitHub Actions и кэшируются; перегенерируются только изменённые фразы. Локально:

```bash
python -m venv .venv && . .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install --index-url https://download.pytorch.org/whl/cpu torch torchaudio
pip install -r tools/tts/requirements.txt
npm run tts                                       # нужен ffmpeg в PATH
```

Для проверки на слух можно синтезировать несколько клипов: `npx tsx tools/tts/plan.ts --cache .tts-cache && python -m tools.tts --cache .tts-cache --limit 20`.

Silero распространяется по лицензии CC BY-NC 4.0 (некоммерческое использование труппой). Лицензию каждого голоса Piper проверяйте по карточке модели.

## Деплой на GitHub Pages

1. Settings → Pages → Source: **GitHub Actions**.
2. Environment `github-pages` — только для ветки `main`.
3. Защитить `main`: обязательный зелёный workflow `ci`.
4. Dependabot уже настроен (`.github/dependabot.yml`).

Каждый push в `main` запускает `.github/workflows/deploy.yml`: разбор, синтез недостающих клипов, тесты, сборка, e2e, публикация на `https://veldmord.github.io/text-learning/`. Pull request проверяет `ci.yml`, в том числе бюджеты Lighthouse CI.

Сайт и текст пьесы публичны. Если нужно скрыть сайт от поисковиков, добавьте в `index.html` `<meta name="robots" content="noindex">` (см. раздел 16 документа).
